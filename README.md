# Bright Path Computer Institute Website

A clean and well-structured multi-page website built as my **very first project** after completing my HTML training on YouTube with **Prashant Sir**. This project serves as the foundational milestone of my web development journey.

## 🚀 Features
* **Multi-Page Layout:** Structured semantic navigation including Home, Gallery, Courses, Contact Us, and About sections.
* **Image Galleries:** Integrated visual showcases of classroom environments and computer setups using optimized image elements.
* **Interactive Forms:** Built-in dynamic data-entry forms for student registrations and user feedback queries.
* **Semantic HTML:** Clean, readable code using standard tags to ensure proper document architecture.

## 🛠️ Tech Stack
* **HTML5** - Layout structure, forms, and core content elements.

## 💡 What I Learned
Through this project and Prashant Sir's guidance, I mastered the usage of anchor tags for inner-page navigation, grouping input types inside forms, organizing directories for local images, and structuring layouts systematically.
